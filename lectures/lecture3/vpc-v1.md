# VPC v1

![VPC v1](../../assets/vpc-v1.png)

## 顧客セグメント
サッカーチームの出欠管理を行う管理者

## Jobs
- 当日の出欠状況を一目で確認したい
- 休む理由を簡単に確認したい
- バス利用の有無を把握したい
- 未回答者へ素早く連絡したい

## Pains
- LINEやメールで回答が分散して確認が面倒
- 誰が未回答か分からない
- 休む理由が会話に埋もれてしまう
- 当日に急な人数不足に気づく

## Gains
- 出欠状況を一画面で確認できる
- 未回答者がすぐ分かる
- 回答が自動集約される
- スマホから簡単に回答できる

## Value Proposition
サッカーチーム用出欠管理Webアプリ
